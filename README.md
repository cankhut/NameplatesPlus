# Nameplates+

A mod that lets you pick colors for the text and background of your nameplate.

## Opening the picker

Press "**N**" or go mods config, The key can be changed under Controls.

Click **Text** or **Background**, then drag in the square for shade, the rainbow strip for hue and the chequered strip for opacity. The hex box takes `#RRGGBB` if you'd rather type the colors hex code instead. **Reset** button puts your nameplate back to vanilla.

Turn on **Show my nameplate in F5** to see your own nameplate in third person while you try out colours.

## Install

It's a server-sided mod but players without the mod can still join, they just see normal nameplates. On a server without the mod your colors aren't shown.

## Building

```
./gradlew build
```

The jar lands in `build/libs/`.
